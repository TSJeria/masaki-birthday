PHOTO PLACEHOLDERS

Upload your own images to this folder using these exact filenames:

photo_1.jpg  -> main photo shown after Masaki submits and on birthday page
photo_2.jpg  -> optional second photo shown near the end on Saturday
photo_3.jpg  -> optional third photo shown near the end on Saturday

You can use PNG instead, but if you do, update PHOTO_FILES in config.py.

Recommended:
- portrait or couple photo
- JPG
- around 1200-1800 px wide
- avoid very large files (>5 MB each)
